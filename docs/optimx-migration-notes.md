# Future OptimX migration

The current live iurugby.com site is managed by OptimX. This Phase 1 Preview is a separate application and is not an immediate cutover.

No OptimX markup, CSS, JavaScript, templates, photos or proprietary components were copied. The public UI is original, using text and CSS shapes. No new sponsor logos, roster members, match results or real-looking fixture content were invented.

Before a future migration, the team should review its actual licensing agreement, rights to content/images, permitted exports, data portability, and termination/renewal terms. The private contract has not been reviewed, and this document makes no claims about its terms. Use team-owned or expressly authorized material.

Keep the live website, OptimX account, Kuntz configuration, payment infrastructure and DNS unchanged until a separate authorized rollout plan covers content ownership, backups, redirects, testing and domain cutover.
